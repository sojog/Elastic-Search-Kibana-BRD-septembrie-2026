## Construirea unui index cu mapping de la inceput
PUT magazie
{"mappings": 
    {"properties": {
            "price":{"type": "float"},
            "stock":{"type": "long"},
            "created_at":{"type":"date"},
            "category":{"type":"keyword"},
            "brand":{"type":"keyword"},
            "description":{"type":"text"},
            "name":{
                "type":"text",
                "fields": {
                    "keyword":{"type": "keyword"}
                }
            }

        }
    }
}

## Diferenta intre text vs keyword
# 1. Cautare dupa text
GET magazie/_search
{"query": {"match": {
  "description": "professional laptop"
}}}

# 2. Cautare dupa keyword
# keyword este folosit cu match
GET magazie/_search
{"query": {
    "term": {
      "category": {
        "value": "laptops"
      }
    }
}}

GET magazie/_search
{"query": {
    "term": {
      "category": {
        "value": "Laptops"
      }
    }
}}

GET magazie/_search
{"query": {
    "term": {
      "brand": {
        "value": "apple"
      }
    }
}}


GET magazie/_search
{"query": {
    "term": {
      "brand": {
        "value": "Apple"
      }
    }
}}

## Cautare keyword in field name
GET magazie/_search
{"query": {
    "term": {
      "name.keyword": {
        "value": "Apple MacBook Pro"
      }
    }
}}

## Exact match nu functioneaza fiindca este cautare pe keyword

{"query": {
    "term": {
      "name.keyword": {
        "value": "apple macbook pro"
      }
    }
